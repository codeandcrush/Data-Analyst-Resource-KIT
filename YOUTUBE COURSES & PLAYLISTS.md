## 🧭 How to Use This Section

Don't watch everything.

Use the videos according to your current phase:

```text id="z1p8pf"
🗺️ ROADMAP
     ↓
🎯 Identify your current skill
     ↓
🎥 Choose ONE primary video/course
     ↓
🧪 Practice alongside it
     ↓
🚀 Build something
     ↓
🏆 Complete the milestone
```

> ⚠️ **Watching a 35-hour bootcamp is not the same as becoming job-ready.**
>
> Pause → Practice → Build → Repeat.

# 🏆 Don't Watch — Build

The biggest trap with YouTube learning is **tutorial consumption without implementation**.

Use this rule:

```text id="j9f3k0"
🎥 30 min watching
        +
🧪 60 min practicing
        +
🚀 60 min building
```

Instead of:

```text id="9v4u4h"
🎥 5 hours watching
        ↓
❌ Nothing built
```
