| [FT Visual Vocabulary](https://github.com/Financial-Times/chart-doctor) | Comparing visualization types |

### 📊 Visualization Principles

1. Choose charts based on the analytical question.
2. Remove unnecessary visual clutter.
3. Use meaningful comparisons.
4. Label information clearly.
5. Avoid misleading scales.
6. Explain what the audience should learn.

**🎯 Goal:** Build dashboards that communicate insights clearly without requiring lengthy explanations.
