# 📅 Complete 52-Week Roadmap

## 🟢 Phase 0 — Build the Foundation

### 📊 Weeks 1–4 — Excel Properly

**Learn**

* Formulas
* Lookups
* Pivot Tables
* Data Cleaning
* Conditional Formatting
* Charts
* Keyboard Efficiency

**Build**

Take **3 messy public datasets** and produce a clean summary dashboard for each using **Excel only**.

**🏁 Milestone**

> You can answer a business question in Excel in **under 10 minutes**.

---

### 💼 Weeks 4–6 — How Data & Business Fit Together

**Learn**

* What a database is
* What a data warehouse is
* KPIs
* Metrics
* How companies actually use data

**Build**

Pick a company you know.

Write down:

> **10 metrics you think their analysts track — and why.**

**🏁 Milestone**

> You can explain what a Data Analyst does to a non-technical friend.

---

# 🔵 Phase 1 — Master the Core

### 🗄️ Weeks 6–11 — SQL: The Core Skill

**Learn**

```text
SELECT
WHERE
JOINs
GROUP BY
Subqueries
CTEs
CASE
Date Functions
String Functions
NULL Handling
Window Functions
```

**Build**

* Solve **150+ SQL problems**
* Build a SQL query library
* Answer **30 real business questions** using one dataset

**🏁 Milestone**

> You can write a **window function without looking it up**.

🔥 **This is a major checkpoint.**

---

### 📈 Weeks 11–13 — Statistics You Actually Use

**Learn**

* Descriptive Statistics
* Distributions
* Correlation vs Causation
* Sampling
* Hypothesis Testing
* A/B Testing

**Build**

Analyse a real dataset and write:

> **3 findings + the uncertainty behind each finding**

**🏁 Milestone**

> You can explain a **p-value correctly to a non-technical person**.

---

# 🟣 Phase 2 — Become a BI Analyst

### 📊 Weeks 13–17 — Power BI

**Learn**

* Data Modeling
* Relationships
* Power Query
* DAX Measures
* Visuals
* Filters
* Dashboard Design

**Build**

Start with raw data and go through the complete workflow:

```text
RAW DATA
   ↓
POWER QUERY
   ↓
DATA MODEL
   ↓
DAX MEASURES
   ↓
VISUALS
   ↓
DASHBOARD
```

**🏁 Milestone**

> A published dashboard that a stakeholder can use **without your help**.

---

### 📉 Weeks 17–20 — Tableau & Visual Design

**Learn**

* Worksheets
* Dashboards
* Calculated Fields
* Chart Selection
* Colour
* Layout
* Storytelling

**Build**

Rebuild your Power BI dashboard in **Tableau**.

Then document:

> Which tool suited the task better — and why?

**🏁 Milestone**

> You can defend **every chart choice** you made.

---

# 🟠 Phase 3 — Add Python & Real Analysis

### 🐍 Weeks 20–25 — Python for Analysis

**Learn**

```text
Python Basics
      ↓
Pandas
      ↓
GroupBy
      ↓
Merge
      ↓
Data Cleaning
      ↓
Matplotlib
      ↓
Seaborn
      ↓
Jupyter
      ↓
Reproducible Analysis
```

**Build**

1. Redo one complete Excel analysis using **Pandas**
2. Automate a task that previously took **1 hour every week**

**🏁 Milestone**

> A notebook another analyst can **read and rerun**.

---

### 🚀 Weeks 25–28 — End-to-End Analysis Project

**Learn**

* Question framing
* Data sourcing
* Data cleaning
* Analysis
* Visualization
* Written recommendations

**Build**

Choose **one real business question** and complete the entire process:

```text
BUSINESS QUESTION
       ↓
DATA SOURCE
       ↓
DATA CLEANING
       ↓
ANALYSIS
       ↓
VISUALIZATION
       ↓
INSIGHTS
       ↓
RECOMMENDATION
```

**🏁 Milestone**

> A project with a **recommendation**, not just charts.

---

# 🟡 Phase 4 — Think Like a Business Analyst

### 💰 Weeks 28–32 — Business Analysis Techniques

**Learn**

* Cohort Analysis
* Retention Analysis
* Funnel Analysis
* Segmentation
* RFM Analysis
* Forecasting Basics
* Unit Economics

**Build**

Run:

* 1 Cohort Analysis
* 1 Funnel Analysis

Then quantify the opportunity in **money**.

**🏁 Milestone**

> You can state a finding in **₹ / $**, not percentages alone.

---

### 🗣️ Weeks 32–35 — Communication & Storytelling

**Learn**

* Executive Summaries
* Slide Structure
* Presenting
* Handling Pushback
* Documentation

**Build**

1. Present one project to a non-technical person
2. Get feedback
3. Rewrite your explanation
4. Present it again

**🏁 Milestone**

> Someone outside your field understood your finding **and knew what action to take**.

---

# 🏆 Phase 5 — Build Your Portfolio

### 💻 Weeks 35–39 — Portfolio Building

**Learn**

* Project Selection
* Project Writeups
* GitHub
* Dashboard Hosting
* Personal Website
* LinkedIn

**Build**

Publish:

### ⭐ 3 Complete Projects

Each project should have:

```text
📌 Business Problem
📊 Dataset
🧹 Cleaning
🔎 Analysis
📈 Dashboard
💡 Insights
🎯 Recommendation
📝 Written Story
```

Host the dashboards publicly.

**🏁 Milestone**

> **3 clickable projects**, each with a written story.

---

### ☁️ Weeks 39–42 — Advanced Tooling

**Learn**

* Cloud Data Warehouses
* Git
* Advanced DAX
* dbt Basics
* AI Tools for Analysts

**Build**

* Query a real cloud warehouse
* Version your analysis code
* Use AI to speed up one workflow
* Document how you used it

**🏁 Milestone**

> You are comfortable working **outside Excel and a laptop-only workflow**.

---

# 🔴 Phase 6 — Get Interview Ready

### 🎯 Weeks 42–46 — Interview Preparation

**Learn**

* SQL Under Time Pressure
* Case Studies
* Guesstimates
* Project Deep-Dives
* Behavioural Stories

**Build**

```text
Daily SQL
    +
Timed Tests
    +
Project Explanation
    +
Mock Cases
    +
Behavioural Stories
```

Practise explaining each project in **5 minutes**.

**🏁 Milestone**

> You can solve a **window-function question live while explaining your thinking**.

---

### 💼 Weeks 46–52 — Applying & Standing Out

**Learn**

* Impact-focused Resume
* LinkedIn
* Cold Outreach
* Referrals
* Domain Specialisation

**Build**

* Apply consistently
* Publish **2 analyses publicly**
* Choose one domain
* Go deeper into that domain

Possible domains:

```text
🛒 Retail
💳 FinTech
🏥 Healthcare
🚚 Logistics
📱 SaaS
📣 Marketing
🏦 Banking
```

**🏁 Milestone**

> Your work becomes discoverable and gives people a reason to contact you.
